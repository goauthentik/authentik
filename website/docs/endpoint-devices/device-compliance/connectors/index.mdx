Connectors allow device information to be reported to authentik. Connectors for third-party services like Fleet can be used standalone or alongside the [authentik Agent](../../authentik-agent/index.mdx) connector.

## Available connectors

The following connectors are currently available:

- [authentik Agent connector](./authentik-agent.mdx): Integrates with the [authentik Agent](../../authentik-agent/index.mdx)
- [Fleet connector](./fleetdm.mdx): Imports device information from [Fleet](https://fleetdm.com/) for device compliance and conditional access.
- [Google Chrome connector](./google-chrome.mdx): Uses Chrome Enterprise Device Trust signals for conditional access.

## Connectors in development {#connectors-in-development}

- **Microsoft Intune**: Imports information about Intune-managed devices through Microsoft Graph. The Endpoint stage can match a client certificate to an imported device.
- **Microsoft Entra ID and Cloudflare WARP**: Separate device connectors are in development. The existing [Microsoft Entra ID provider](../../../add-secure-apps/providers/entra/index.mdx) synchronizes users and groups, not devices.

## Manage connectors

Use the following instructions to manage your connectors:

### Add a connector

For connector-specific settings, see the [authentik Agent](./authentik-agent.mdx), [Fleet](./fleetdm.mdx), or [Google Chrome](./google-chrome.mdx) connector documentation.

1. Log in to authentik as an administrator and open the authentik Admin interface.
2. Navigate to **Endpoint Devices** > **Connectors** and click **Create**.
3. Select the connector type, click **Next**, and configure the following required settings:
    - **Connector name**: Provide a descriptive name for the connector.
    - **Refresh interval**: Select how often the agent updates its configuration.
    - **Enabled**: Enable or disable the connector.
4. Click **Finish**.

### Edit a connector

1. Log in to authentik as an administrator and open the authentik Admin interface.
2. Navigate to **Endpoint Devices** > **Connectors**.
3. Click on the connector that you wish to edit.
4. Update any settings that you want to change.
5. Click **Update**.

### Delete a connector

1. Log in to authentik as an administrator and open the authentik Admin interface.
2. Navigate to **Endpoint Devices** > **Connectors**.
3. Select the connector that you wish to delete.
4. Click **Delete**.
