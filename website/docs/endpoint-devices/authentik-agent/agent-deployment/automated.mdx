The authentik Agent can be deployed at scale to multiple devices via Mobile Device Management (MDM) and automation tools.

To enforce authentik Agent settings on devices, refer to [Agent settings and policies](../settings.mdx#enforce-settings-with-a-policy).

## Prerequisites

You must [configure your authentik deployment](../configuration.mdx) to support the authentik Agent.

## Create an enrollment token

If you have already created an enrollment token, skip to the next section.

1. Log in to authentik as an administrator and open the authentik Admin interface.
2. Navigate to **Endpoint Devices** > **Connectors**.
3. Click on the authentik Agent connector that you created when [configuring your authentik deployment](../configuration.mdx) to support the authentik Agent.
4. Under **Enrollment Tokens**, click **New Enrollment Token**, and configure the following settings:
    - **Token name**: provide a descriptive name for the token
    - **Device group _(optional)_**: select a device access group for the device to be added to after completing enrollment
    - **Expiring _(optional)_**: set whether the enrollment token expires.
5. Click **Create**.

## How automated enrollment works

Each of the following sections deploys an enrollment configuration to a device. It contains the URL of your authentik deployment and an enrollment token. The authentik system service (`ak-sysd`) reads the configuration when it starts and joins the device to an authentik domain named `ak-mdm-managed`.

With authentik Agent 0.73.1 and later:

- If the device was also joined to a domain manually, the domain from the enrollment configuration takes priority.
- If the enrollment configuration is removed from the device, the system service removes the `ak-mdm-managed` domain the next time it starts.
- You can list the domains that a device has joined, and which one is active, with the `ak-sysd domains list` command. Run the command with administrative privileges and use the path of `ak-sysd` for your platform, for example on Linux:

```sh
sudo ak-sysd domains list
```

## Linux

Automated enrollment on Linux requires authentik Agent 0.70 or later.

1. Create the file `/etc/authentik/managed.json` with the following content:

```json
{
    "url": "https://authentik.company",
    "registration_token": "<enrollment_token>"
}
```

2. Ensure that the file is owned by `root` and that only `root` can read it. The system service ignores the file if the group or others have any permissions on it.

```sh
sudo chown root:root /etc/authentik/managed.json
sudo chmod 0400 /etc/authentik/managed.json
```

3. [Install the authentik Agent packages](./linux.mdx#install-the-authentik-agent-on-linux). If the packages are already installed, restart the system service:

```sh
sudo systemctl restart ak-sysd
```

## Windows

1. Log in to authentik as an administrator and open the authentik Admin interface.
2. Navigate to **Endpoint Devices** > **Connectors**.
3. Click on the authentik Agent connector that you created when [configuring your authentik deployment](../configuration.mdx) to support the authentik Agent.
4. Under **Setup**, select the enrollment token that you wish to use for enrolling devices.
5. Click **Windows** and then click either **Download** or **Copy** to obtain your SyncML MDM configuration snippet.

This SyncML snippet can be used by Microsoft Intune, Microsoft Endpoint Manager, and other MDM tools to deploy the changes required to support the authentik Agent.

The following two registry keys (`REG_SZ`) are added by the configuration snippet:

- `HKLM/SOFTWARE/authentik Security Inc./Platform/ManagedConfig/RegistrationToken`
- `HKLM/SOFTWARE/authentik Security Inc./Platform/ManagedConfig/URL`

## macOS

1. Log in to authentik as an administrator and open the authentik Admin interface.
2. Navigate to **Endpoint Devices** > **Connectors**.
3. Click on the authentik Agent connector that you created when [configuring your authentik deployment](../configuration.mdx) to support the authentik Agent.
4. Under **Setup**, select the enrollment token that you wish to use for enrolling devices.
5. Click **macOS** and then click either **Download** or **Copy** to obtain your MDM policy.

This policy can be used by Apple Business Manager, Fleet, and other MDM tools to deploy the changes required to support the authentik Agent.

:::warning MDM only
Apple requires an MDM tool to apply this policy to a device. The policy does not work when applied manually.
:::

### User registration

After the authentik Agent is deployed to a device, the user receives a notification asking them to register with authentik. The registration flow prompts the user to authenticate with authentik. After authentication, authentik enrolls the device and associates it with the user.
