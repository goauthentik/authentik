The authentik Agent can authenticate to CLI applications such as:

- [the AWS CLI (`aws`)](./aws.mdx)
- [the Kubernetes CLI (`kubectl`)](./k8s.mdx)
- [Claude Code](/integrations/development/claude-code/), by exchanging the developer's authentik token for a short-lived Anthropic access token

## How CLI authentication works

First, `authentik-agent` and `authentik-cli` request an authentik token from the [authentik-cli OAuth Provider](../../configuration.mdx#create-an-application-and-provider-in-authentik-for-cli) and exchange it for a token from the specified Kubernetes or AWS provider.

This token is cached until expiration. This improves performance by eliminating repeated token requests.
