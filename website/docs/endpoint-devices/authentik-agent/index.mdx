## What is the authentik Agent?

The authentik Agent is a service that can be installed on Linux, macOS, and Windows devices. It provides the following capabilities:

- [Device compliance](../device-compliance/index.mdx) by reporting information about endpoint devices to authentik
- [Local device login](./device-authentication/local-device-login/index.mdx) with authentik credentials
- [Connecting via SSH to endpoint devices](./device-authentication/ssh-authentication.mdx) with authentik credentials
- [Authenticating to CLI applications](./device-authentication/cli-app-authentication/index.mdx) such as kubectl and AWS with authentik credentials
- [Giving AI clients delegated access](./mcp-server.mdx) to applications and the authentik API through an MCP server

## authentik Agent components

The authentik Agent consists of several components:

| Platform                  | Component                           | Description                                                                                                                                                                                                                                                                                                                       | Dependencies      |
| ------------------------- | ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------- |
| **Linux, macOS, Windows** | `authentik-cli`                     | Provides CLI commands for interacting with `authentik-agent`.                                                                                                                                                                                                                                                                     | `authentik-agent` |
| **Linux, macOS, Windows** | `authentik-agent`                   | User agent that handles authentication within a user's context, for CLI tools, SSH, and the browser extension. On macOS and Windows, it's part of the [authentik Agent app](./desktop-app.mdx). On Linux, install either the headless `authentik-agent` package or the `authentik-agent-desktop` package, which includes the app. | None              |
| **Linux, macOS, Windows** | `authentik-sysd`                    | Responsible for handling device-level authentication and compliance checks.                                                                                                                                                                                                                                                       | None              |
| **Linux only**            | `libpam-authentik`                  | PAM Module for token-based and interactive authentication via authentik. Used for [SSH authentication](./device-authentication/ssh-authentication.mdx) and [local device login](./device-authentication/local-device-login/index.mdx).                                                                                            | `authentik-sysd`  |
| **Linux only**            | `libnss-authentik`                  | NSS Module that makes Linux aware of authentik users. All authentik users are visible to Linux but cannot log in unless configured through device access groups. Provides a consistent `uid` and `gid` for users on all endpoint devices.                                                                                         | `authentik-sysd`  |
| **Windows only**          | `Windows Credential Provider` (WCP) | Enables logging in to Windows devices using authentik credentials.                                                                                                                                                                                                                                                                | `authentik-sysd`  |

## Technical information

All authentik Agent components communicate via gRPC and Unix domain sockets/Windows named pipes.

**Linux**: `/var/run/authentik/sys.sock` and `/var/run/authentik/sys-ctrl.sock`
**macOS**: `/var/run/authentik-sysd.sock` and `/var/run/authentik-sysd-ctrl.sock`
**Windows**: `\\.\pipe\authentik\sysd` and `\\.\pipe\authentik\sysd-ctrl`

- `sys.sock`/`*sysd.sock` for general communication
- `*-ctrl.sock` for domain join

The user agent provides the following sockets and named pipes in the user's context:

| Platform | `ak` CLI                                             | SSH agent                                                |
| -------- | ---------------------------------------------------- | -------------------------------------------------------- |
| Linux    | `~/.local/share/authentik/agent.sock`                | `~/.local/share/authentik/agent-ssh.sock`                |
| macOS    | `~/Library/Application Support/authentik/agent.sock` | `~/Library/Application Support/authentik/agent-ssh.sock` |
| Windows  | `\\.\pipe\authentik\socket-<session_id>`             | `\\.\pipe\authentik\socket-ssh`                          |

The user agent also provides an SSH agent socket for each profile. Refer to [SSH authentication](./device-authentication/ssh-authentication.mdx#use-a-specific-profile-for-a-host).

## Telemetry

The authentik Agent reports errors to authentik's Sentry by default. The authentik Agent app also checks at most once a day whether a newer release exists and sends an anonymous analytics request when it starts.

You can disable error reporting of the user agent, including the authentik Agent app, and the app's update check with the `telemetry` settings. Refer to [Agent settings and policies](./settings.mdx). Only the `AUTHENTIK_DISABLE_STARTUP_ANALYTICS` environment variable disables the analytics request. Error reporting of the other components, such as `authentik-sysd` and `authentik-cli`, can't currently be disabled.
