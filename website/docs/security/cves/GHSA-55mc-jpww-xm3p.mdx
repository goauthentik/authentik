## Unauthenticated Access via Path Normalization Differential in Nginx Forward-Auth Mode

### Summary

In nginx forward-auth mode, the outpost exempts its own internal endpoints from authentication. The gateway and the outpost resolve the request path differently, so a crafted request can claim that exemption and be served as a protected resource instead.

### Patches

authentik 2026.5.9 and 2026.8.7 fix this issue.

### Impact

**Only the nginx forward-auth integration is affected.**

Resources behind the integration can be read and modified. Access is anonymous; no user is impersonated.

### Workarounds

None. We recommend not using the nginx forward-auth integration until upgrading.
