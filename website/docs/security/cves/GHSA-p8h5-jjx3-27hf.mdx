## Cross-site scripting via sent emails in the event log

### Summary

Opening a sent email in the event log ran any script the email contained.

### Patches

authentik 2026.5.9 and 2026.8.7 fix this issue.

### Impact

**All deployments are affected. By default, only superusers and outposts can exploit this issue.**

Anyone allowed to create events can add such an email and run JavaScript in the session of whoever opens it.

### Workarounds

None. We recommend not opening or expanding sent emails in the event log until upgrading.
