## Command execution via Kubernetes outpost integrations

### Summary

The kubeconfig of a Kubernetes outpost integration could make the server run arbitrary commands and disclose local secrets.

### Patches

authentik 2026.5.9 and 2026.8.7 fix this issue.

### Impact

**Only users who can create or edit Kubernetes outpost integrations can exploit this.**

Such a user can take over the identity provider and every account it manages.

### Workarounds

Only grant permission to create or edit Kubernetes outpost integrations to superusers.
