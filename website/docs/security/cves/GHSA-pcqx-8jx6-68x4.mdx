# GHSA-pcqx-8jx6-68x4

_Reported by [@melizeche](https://github.com/melizeche), [@wonark-prov](https://github.com/wonark-prov), [@Huge](https://github.com/Huge), [@SounLabs](https://github.com/SounLabs), [@codemath3000](https://github.com/codemath3000)_

## Unbounded decompression of SAML messages

### Summary

The server decompressed SAML messages from any client without limiting their size.

### Patches

authentik 2026.5.9 and 2026.8.7 fix this issue.

### Impact

**All deployments are affected, whether or not they use SAML.**

A short burst of small requests can exhaust the server's memory and interrupt service for all users while the requests continue.

### Workarounds

None. We recommend blocking requests to `/application/saml/` at the reverse proxy until upgrading if you do not use SAML applications.
