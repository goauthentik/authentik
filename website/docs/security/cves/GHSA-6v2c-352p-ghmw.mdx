## Federated JWTs matched to existing users by username

### Summary

A JWT from a federated OIDC source could be matched to any existing user whose username it carried.

### Patches

authentik 2026.5.9 and 2026.8.7 fix this issue.

### Impact

**Only deployments where an OAuth2 provider accepts JWTs from federated OIDC sources are affected.**

Anyone who can get such a source to issue a JWT with a username of their choice can act as any existing user wherever that provider's tokens are accepted. Doing so also turns that user's account into a service account.

### Workarounds

None. We recommend making sure that users of the identity providers configured as federated OIDC sources cannot set their own username or nickname until upgrading.
