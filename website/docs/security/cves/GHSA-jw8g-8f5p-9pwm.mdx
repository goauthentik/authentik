# GHSA-jw8g-8f5p-9pwm

## Flow stages skipped on errors during policy execution

### Summary

A flow stage controlled by a policy could be skipped when an error occurred during that policy's execution, even if its binding was set to pass on failure.

### Patches

authentik 2026.5.9 and 2026.8.7 fix this issue.

### Impact

**Deployments that use the default authentication flow, or other flows where policies decide whether a stage is shown, are affected.**

While errors occur during policy execution, for example because the database's disk is full, anyone who knows a user's username or email address can sign in as that user without their password or second factor.

### Workarounds

None. We recommend making sure the database cannot run out of disk space until you upgrade.
