## Authentication bypass in proxy providers via path normalization differential

### Summary

A proxy provider checked requests against its Unauthenticated Paths or Unauthenticated URLs without normalizing the path the way the protected application does.

### Patches

authentik 2026.5.9 and 2026.8.7 fix this issue.

### Impact

**Only proxy providers with Unauthenticated Paths or Unauthenticated URLs entries that match more than an exact path are affected.**

Protected resources can be read and, because the request method is preserved, modified.

### Workarounds

Until you upgrade, limit Unauthenticated Paths and Unauthenticated URLs to entries that match exact paths, such as `^/health$`, or remove them.
