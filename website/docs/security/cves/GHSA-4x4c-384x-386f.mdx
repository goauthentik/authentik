## Webhook responses disclosed by notification transport tests

### Summary

Testing a webhook notification transport returned the receiving server's response, not just its status.

### Patches

authentik 2026.5.9 and 2026.8.7 fix this issue.

### Impact

**Only deployments where users other than superusers can add and change notification transports are affected.**

Such users can read responses from internal web services reachable from the server.

### Workarounds

None. We recommend letting only superusers add and change notification transports until upgrading.
