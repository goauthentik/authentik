A provider property mapping runs a Python expression to produce the data that the provider sends to the integrated application. The documentation for each provider lists the types that its mappings must return. Returning `None` skips the mapping.

## Available context

- `request`: an authentik [policy request object](../../../customize/policies/types/expression/reference.mdx#request). Use `request.user` for the contextual user and `request.context` for additional context data.
- `request.http_request`: the underlying Django request when one is available. This value can be `None`. See the [Django request documentation](https://docs.djangoproject.com/en/stable/ref/request-response/).
- `user`: the contextual user when the mapping type provides one. See [User object properties](../../../users-sources/user/user_ref.mdx#object-properties).
- `group`: the contextual group when the mapping type provides one.

Providers can add more variables, such as `provider`, `token`, or `endpoint`. Refer to the provider's documentation for the variables that each mapping type receives.
