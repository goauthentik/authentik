## Available context

- `request`: an authentik policy request object. Use `request.user` for the contextual user and `request.context` for additional context data.
- `request.http_request`: the underlying Django request when one is available. This value can be `None`. See the [Django request documentation](https://docs.djangoproject.com/en/stable/ref/request-response/).
- `user`: the contextual user when the mapping type provides one.
- `group`: the contextual group when the mapping type provides one.

The `user` and `group` variables are only available when the mapping context includes them. Refer to the documentation for the mapping type before you use these variables.

A provider can add more variables, such as `provider`, `token`, or `endpoint`. Refer to the provider documentation for the context available to that mapping type.
