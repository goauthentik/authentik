Rotating replaces a [secret](./index.mdx)'s value with a freshly generated one. Only text secrets can be rotated; multi-line and file secrets keep their value until you change it by hand.

Rotation changes the value for every object referencing the secret. Update every external client that uses it. Connected outposts are notified after the change is committed and use the new value after reloading their configuration.

:::warning
Only rotate a secret whose value another system issued (an OAuth source's consumer secret, an SMTP password, and the like) if that system accepts the value authentik generates, which is rarely the case. See [Secrets authentik does not generate](./index.mdx#secrets-authentik-does-not-generate).
:::

Under **System** > **Secrets**, click **Rotate secret**, then **Rotate** to confirm. This takes the **Rotate secret's value** permission.

Forms that select a text secret expose the same action beside the selector. Rotation takes effect even if you cancel the surrounding form. If you also have the **View secret's value** permission, authentik shows the new value after rotation so you can copy it to the client.

## Auditing

Rotation and explicit value replacement are recorded as a [`secret_rotate`](../events/event-actions.mdx#secret_rotate) event.
